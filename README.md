# Expense-Tracker-Excel
Developed an excel-based finance dashboard with automated reporting, and interactive filters using Pivot Tables and advanced formula

## Features
- Transactions for March 2025
- Category-based analysis
- Interactive dashboard
- Budget monitoring
- Overspending alerts

## Data & Process
- Collected daily transaction data
- Cleaned and structured using Excel Tables
- Analyzed using Pivot Tables
- Visualized using a donut chart and slicers
- Applied budget rules with conditional formatting

## Insights & Key Findings
In March 2025, total expenses amounted to RM4,820.83.

- Using pivot analysis, the top spending category was identified. 73% of expenses were allocated to planned transfers, reflecting
  structured financial commitments.
- Food, transport, and bill expenses remained within budget.
- Shopping expenses were close to the monthly limit, indicating
  potential impulse spending.
- No major spending spikes were observed, showing stable financial
  behaviour.
